# Баланс и оценка себестоимости

Только админ «Мониторинг». Клиенту и в тариф не показываем.

| Метод | Вызов | Списывает SMSC? |
|---|---|---|
| Баланс кабинета | `POST /sys/balance.php` | нет |
| Оценка | `POST /sys/send.php` + `cost=1` + `hlr=1` или `ping=1` | нет (режим цены) |
| Проверка связи | баланс + локальная проверка подписи | нет; **никогда** не вызывает submit |

Кэш баланса в Redis: ключ `sms:provider:smsc:balance` (в старом HLR был `hlr:provider:smsc:balance`). Пишет отдельный тикер раз в 2 минуты (`balance.php`, не из lookup Tick) и админ-зонды «Баланс» / «Проверить связь» после успеха. TTL 3 минуты. Секрет в Redis не класть. Нет кредов или пустой кэш — метрика `fn_smsc_balance` отсутствует, не ноль. `/readyz` от SMSC не зависит.
