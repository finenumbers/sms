# HLR

`POST /sys/send.php` с `hlr=1`, `fmt=3`, `phones`, клиентский `id`.

После ack статус часто ещё `pending`. Финал — callback и/или `status.php`.

Если в финале нет IMSI или `extras.msc` — повторный `status.php?all=2`, в нормализованный результат пишем только непустые поля (enrichment). Это часть продукта, не оптимизация.

Пилот платформы: только `+79XXXXXXXXX` (11 цифр, начинается с 79).
